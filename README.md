# THE WORLD TODAY — a one-page front page for 26 November 2026

This repository paints a single 1024 by 1024 newspaper sheet that sums up Thursday 26 November 2026, led by the centenary Macy's Thanksgiving Day Parade in New York — a record hundred balloons, with a nor-easter threatening to keep them on the ground.
Around the lead, four illustrated stories fill a two-by-two grid: Colombian troops freeing all twenty hostages from a Cartagena supermarket after a seventeen-hour siege; Australia and Solomon Islands signing a sweeping security treaty; leaked Russian records analysed by the BBC putting war deaths in Ukraine near five hundred thousand; and Malaysia suing Google for a hundred and forty-six million dollars over YouTube content.
A strip along the foot adds two more items from the day: Bangladesh garment workers winning a thirty-six percent pay rise to seventeen thousand taka a month, and India marking Constitution Day while calling for human control over AI weapons.
## How to run it
Run `python3 ./main.py` to place the finished picture at `/output/entry.png` — a 1024 by 1024 PNG of 131355 bytes, byte-identical on every run because the picture is painted once by `render.py` and only copied by `main.py`.
`render.py` does the painting with Pillow at build time, while `main.py` uses only the Python standard library, checks the PNG size and signature, and verifies the copied bytes against the original before it reports success.
